## 固定资源流量

当前资源包包含 5,548 个文件：图片、Spine 骨骼与图集、音频、字体、棋盘模型 / 元数据、固定样式和明确列出的公开游戏 JSON。包为 273,691,120 字节（约 261 MiB）；内容版本与 v0.2.7 相同。

测试直接编译发布客户端使用的 ResourceCache.cs，并通过实际 HTTP 服务统计请求。逐项核对项目全部资源的普通路径、URL 编码路径、带查询参数路径、版本化路径和 HEAD；读取内容与清单 SHA-256 一致。预置资源包的两次准备与全部本地读取只请求两次小型版本描述，没有请求资源目录清单、ZIP、单文件或原始素材路径，因此固定资源正文传输为 0 字节。

| 场景 | 实测结果 |
| --- | --- |
| 轻量版空缓存首次准备 | 1 次清单 + 1 个完整 ZIP，随后从本地读取 |
| 未变化资源再次启动 | 0 清单 / ZIP / 单文件下载，固定资源正文 0 字节 |
| 仅游戏代码更新 | 固定资源不重下 |
| 测试素材改变 | 新清单 + 1 个改变文件，其余正确文件不下 |
| 测试文件损坏 | 仅修复该文件，不重下清单或完整包 |
| 安装包预置资源匹配服务器 | 0 清单 / ZIP / 单文件下载 |
| 空缓存 ZIP 中断重试 | Range 从已有偏移续传 |
| 有完整缓存文件且残留部分 ZIP | 只下载缺少文件，已保存文件没有再次请求 |
| 资源缺失或版本不匹配 | 本地报错并提示局外更新，不回退下载素材 |

当前 /app/resource-manifest JSON 正文为 796 字节；不包括 HTTP、TLS 或传输层开销。固定资源零传输不代表联机游戏零流量：HTML、JavaScript / 前端库、登录状态、成绩和对局通信仍由服务器提供并校验。
