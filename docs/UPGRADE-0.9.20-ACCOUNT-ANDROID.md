# 0.9.20 管理员账号操作与安卓横屏

管理员在浏览器打开服务器的 `/account`，登录后进入“账号列表”。其他账号现在有“重置密码”和“删除账号”按钮。自己的密码仍从“我的账号”修改，不能删除自己。

重置密码需要输入两次临时密码，至少6个字符。成功后该玩家原有登录会失效，账号ID、赞助状态、调配、统计与历史保持。玩家需在浏览器登录并修改临时密码，随后返回客户端登录。删除需输入完全一致的目标账号名确认；删除账号会终止现有登录，不清空历史战绩、统计或其他账号的数据。统计清空仍是独立的管理员操作。

安卓新完整客户端为 **0.9.20 / build46**，同包名、同签名，内嵌完整资源，可直接覆盖安装。默认请求正向或反向横屏；系统仍强制竖屏时，原生提示层显示“请横屏游玩”并遮住操作，回到横屏自动恢复原页面，不主动刷新WebView或断开连接。提示层在未连接服务器时也可显示。旋转不暂停服务器对局。Windows继续使用既有完整-r2客户端 build45。

资源版本保持 `41ebe63b7a079fc34814e9e9714b166dff45f1a681d96035497b6278b7f7314a`，contract2 / line0.9 / epoch1，服务器最低兼容构建仍为45，未强制旧Windows更新。服务器不提供完整客户端或完整资源下载。安卓的新原生方向行为必须安装新APK才生效，仅更新服务器不能修改已安装的原生壳。

本包一并纳入共享候选中另一AI已完成的“测试包预设优先于同名自选”修复：本局启用的测试包包含某干员时，排除重复的自选加入；不改玩家保存的选择，关闭包后恢复原候选资格。4个输入与 `reports/testpack-diy-priority-20261103/CHANGED-FILES.json` 一致，复用其6项定向与9项回归记录；没有回退或覆盖这些文件。

## 服务器更新

在原开服终端按 **Ctrl+C**，等待退出并回到命令提示符。上传新包到 `/root/updates`，按顺序逐行执行：

```bash
cd /root/updates
tar -xzf Stronghold-Protocol-3-server-light-v0.9.20-account-android-20261103.tar.gz --strip-components=1 -C /root/w3
cd /root/w3
npm ci --omit=dev
node --env-file="/root/w3/config/server.env" tools/clear-unfinished-matches.mjs --stopped
node --env-file="/root/w3/config/server.env" server/product/game-server.js
```

每行成功后再继续；最后一行保持运行。下次停服仍按Ctrl+C并等待退出。本操作按用户要求不加入检查、备份或 `update-project`。更新包不含真实配置、账号、数据库、调配与统计存档或私钥，覆盖解压保留这些文件。停服清理只删没有最终结果的未完成记录。

更新后刷新账号管理网页。安卓在手机上安装新完整APK后重新打开；覆盖安装无需卸载，避免主动清除应用数据。Windows完全退出并重开现有客户端即可。
