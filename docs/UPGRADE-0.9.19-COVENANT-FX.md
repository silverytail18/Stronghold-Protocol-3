## 更新操作

先在原开服终端按 **Ctrl+C**，等待退出并回到命令提示符。把新包上传到 `/root/updates`。

按顺序逐行执行，每行成功后再执行下一行：

```bash
cd /root/updates
tar -xzf Stronghold-Protocol-3-server-light-v0.9.19-covenant-fx-20261103.tar.gz --strip-components=1 -C /root/w3
cd /root/w3
npm ci --omit=dev
node --env-file="/root/w3/config/server.env" tools/clear-unfinished-matches.mjs --stopped
node --env-file="/root/w3/config/server.env" server/product/game-server.js
```

最后一行是开服命令，保持该终端运行。下一次停服仍在开服终端按 Ctrl+C，等待退出。

更新包不含原服的配置、账号库、数据库、调配存档、统计存档或签名文件，覆盖解压保留这些文件。`--stopped` 工具只在停服时清理没有最终结果的未完成记录，保留已完成历史、积分和可靠待结算结果。本步骤按用户要求不加入检查、备份或 `update-project`。

更新后完全退出并重新打开客户端，账号网页刷新。诊断服务器版本应为 **0.9.19**；原生客户端仍显示 build45 属正常情况。
