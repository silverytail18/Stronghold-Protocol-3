## 简化更新步骤

1. 在旧开服窗口按Ctrl+C，等程序退出、回到命令提示符。
2. 将新的服务器包上传到 `/root/updates/`。
3. 依次执行下列命令。本步骤不运行检查或备份工具。

```bash
cd /root/updates
tar -xzf Stronghold-Protocol-3-server-light-v0.9.18-merged-20261103.tar.gz --strip-components=1 -C /root/w3
cd /root/w3
npm ci --omit=dev
node --env-file="/root/w3/config/server.env" tools/clear-unfinished-matches.mjs --stopped
node --env-file="/root/w3/config/server.env" server/product/game-server.js
```

服务器包不包含config、storage、私有账号数据库、签名、完整资源包或客户端安装器。直接覆盖源码保留原文件；不使用会自动备份的update-project。每行成功后再执行下一行，出现报错时不要继续开服。

清理工具只清除旧版退出后遗留且没有最终结果的running对局及关联记录；不删除已完成战绩、赛季积分或可靠待结算结果。正常Ctrl+C停服现已自动执行收尾。以后直接使用最后两行中的开服命令即可；正常关服按Ctrl+C并等退出，不要连续强杀。

更新后完全退出并重新打开游戏客户端，账号管理网页刷新。游戏诊断中的version应显示0.9.18；客户端Build仍为45是正常的。

## 修复与功能入口

- **皮肤**：自动保存只监听皮肤内容变化，忽略同步状态变化；相同内容不重复写入。调配偏好使用独立的120次/分钟/账号限流，不再占用修改密码等账号操作的10次/15分钟额度。遇429读取Retry-After有限重试，切换账号会取消旧账号重试。
- **问题反馈**：设置中仅提示向服务器管理员反馈，保留复制诊断信息、错误计数和复制失败时的只读文本。没有填写问题或发送反馈对话框；管理员历史收件箱继续保留旧记录。
- **测试包身份整理**：参考目录按正式charId去重，已有正式记录优先，保留其技能、模组、属性与默认配置，并对齐盟约成员及关联引用。多包来源能正确筛选；仍拒绝未适配的本体/测试同身份组合，不凭目录可浏览就允许开局。未来真实版本更新须先逐包适配，详见PRODUCT-CONTENT-IDENTITIES.md。
- **百科与图标**：局外目录继续列出未启用测试包的内容；局内只列本局实际启用的内容。百科统一读取客户端已有的完整本地图片索引，避免历史版本索引漏项，也不把约3.26MB完整索引重复放入服务器百科响应。替换重复的测试包占位图：使用现有干员头像或代码内的独立图形；这类自定义图形不是新提取的原作图标。已有正式图片或外观覆盖保持优先。
- **盟约头像**：放大为56～76px，最多两行高度、超出滚动。
- **管理员领取**：浏览器账号后台→测试包设置→允许管理员测试领取；房间选好允许版本和测试包后开局。第一回合局内左下角有“测试领取”，休整期可开启本人开关并领取所选普通/精锐干员，本局一次；整备区须有空位。权限以实时后台设置和实际账号为准，排位禁用、普通玩家不可使用。仅能领取本局已启用包的干员，未启用包不会被发入对局。
- **少女乐队**：修复局外试听先查中文语音造成日语录音被挡的问题；五人名片立绘进入房间选择列表，不要求启用战斗内容包。使用完整-r2客户端已有图片和语音，不新增素材。
- **专精**：局外专三按钮显示选中状态；塔露拉三技能槽补齐原作十级记录，由原客户端表经上游技能编译器生成，技能数值与共用专精链路一致。
- **玩家统计**：浏览器账号页→玩家统计→点击玩家名字。普通玩家查看公开统计与对局摘要；管理员也可从账号列表点击账号名直达该玩家，展开全部管理数据查看安全账号字段、调配、成就档案、对局、赛季积分流水和关联管理记录。密码哈希、登录令牌、会话等不会返回。
- **统计清空**：游戏客户端移除清空按钮、接口拒绝普通玩家清空。仅浏览器管理员在指定玩家页确认“清空该玩家的成就统计”；不删除账号、赛季积分、服务器战绩或其他玩家统计。旧客户端缓存及旧履历不会在下次同步时把已清空的成就记录恢复。
- **统计筛选**：客户端统计页与浏览器玩家统计默认包含插件对局，可关闭“含插件对局”查看无插件统计；测试房间仍不计入。保留旧无标记历史，不推测其是否使用过插件。
