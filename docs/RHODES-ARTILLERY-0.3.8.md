# 罗德岛炮击平衡与表现 0.3.8

本轮采用 ri-mujica-test-9、客户端能力14，仅启用“罗德岛与乐队”生效。覆盖此前3200＋90L及6人150%攻击力系数公式，保留0.3.7的两项互斥禁用测试和既有内容。已先交候选包，随后完成211项回归与三难度342场正式波次，结果见RHODES-VALIDATION-0.3.8.md。

层数L限制0—999，A为本人存活在场罗德岛成员当前攻击力总和，包含当时技能、装备及盟约攻击增益。设D=max(0,L−220)，P=min(1,D/580)：

- 每发物法底伤B=100＋2L＋0.1D²。
- 6人攻击系数C=4%＋96%×P，上限100%；每发F=B＋C×A。
- 9人攻击系数C=4%＋196%×P，上限200%；每发物法F=B＋C×A，真实弹为50%F。
- 220层以前保持低底伤、4%攻击供给；220—800层逐步成长，无回合10的突变或伤害预算硬锁。

在相同84层、A约4732的第7回合复现条件下，6人每发减伤前伤害由约17858降至约457。实际伤害还要经过护甲、法抗、闪避及剩余生命限制。

6人每3秒物法双发，半径1.2格、每弹最多3目标；9人每2秒物法真三发，半径1.5格范围全体。各弹优先不同主目标，数量不足才重复。固定地面落点，不追踪。发射至爆破6人0.5秒／9人0.4秒；主锁定目标该期间减速50%，同名取最高，不叠加、不增加爆破后减速。

炮弹沿原直线轨迹快速下落；暖橙／蓝紫／淡金弹各保留12°／18°／6°倾角。弹芯、短尾和小光晕增强，只有空中弹体采用加色，地面范围圈和命中保留正常混合；范围圈不填满、无屏幕白闪和长光柱。9人弹芯稍大，保持三弹与更快节奏的升级感。降落、光晕与爆破同步，不延迟伤害反馈。

属性、屏障、角色和成长条件保持。因为降低火力会延长承压时间，多职业休整额外成长从1/6/6调整为1/4/4；基础1/4/7、有效炮击上限24/30、协同24/30、临光10/20等保持。典型普通／困难20回合约800层仍为目标；深渊可因战斗更长而更高。

第1—9回合每场本人炮火实际伤害／本人阵容实际伤害≤50%为平衡目标；第15—19回合合计炮火输出≥60%。按真实扣血计算，不使用过量伤害或全程占比掩盖前期问题。这是典型阵容验收标准，极端缺乏干员输出、长期失能、提前九人或特殊站位仍可能超出；没有新增所有阵容硬锁50%的机制。
