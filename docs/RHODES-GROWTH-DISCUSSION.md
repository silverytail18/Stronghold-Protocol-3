# 罗德岛后期成长缺口（2026-10-08，讨论稿）

本稿解释0.3.0 r2实际机制，提出后续选择；0.3.0 r3仅修装备显示和音符外观，未实施本稿数值。

当前罗德岛主要由休整结算成长：3／6／9人基础2／4／6层，加上各新角色满足条件后的定额收益。同一角色普通／精锐只取一份；精锐通常将收益翻倍，但条件达成后不再随回合、开技频率、输出或现有层数继续增长。凯尔希3人3职业／6人4职业的4／8层是一次性奖励。6／9人战斗协同只增伤和屏障，不直接叠层。

例如普通芬＋米格鲁＋阿米娅，三职业条件成立时每轮5层；芬在场且当轮实际买入罗德岛才再加1层。精锐阿米娅、刻俄柏、若麦、睦、米格鲁、初华的六人组合，在所有对应条件成立时每轮20层。但用保留旧特质的泥岩、百炼嘉维尔、妮芙、予愿等替换后，原目标盟约的收益不会自动改为罗德岛。成员计数与成长来源并不等价，因此成型后换入终端可能反而减少专属成长。

旧成员有例外：波登可的最高已激活盟约成长可作用于罗德岛；华法琳赋予前方干员的开技成长会增加其自身已激活盟约，罗德岛也可受益；魔王可追加前方干员实际触发的特质成长。它们需要层数、站位或借用特质条件，不能视为所有罗德岛成员自带的成长。作为对照，百炼嘉维尔普通特质每次开技使萨尔贡+9，实际可借战斗频率增加成长；此固定目标不会因追加罗德岛归属而改变。

推荐后续将成熟阵容的协同与成长相连：保留3人休整成长；6／9人由两个不同干员、不同职业的正常技能启动成功触发协同时，分别额外+3／+6层。按本人整轮共用上限9／18层，避免多场、多人同场和长战斗重复收益失控；9人开场自动协同不叠层，免费狂热开技不反复制造成长，召唤物和同一角色副本不独立计数。具体事件过滤、结算持久化及客户端展示需后续实现验证。

这样普通六人可通过最多三次有效协同额外获得9层，九人最多18层；旧成员和装备转职成员也能参与，不将后期成长绑定到祥子或保留低阶成长角色。仍需保留角色自身的主要发育特质，防止盟约战斗收益全面取代构筑选择。本稿数值属于待确认的初始测试值，没有胜率验证。
