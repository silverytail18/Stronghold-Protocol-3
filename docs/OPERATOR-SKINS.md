# 干员皮肤（2026-10-07）

在干员调配界面的技能和模组下面选择皮肤。普通与精锐共用所选时装；“默认外观”恢复原来的普通／精锐美术。选择在当前客户端保存，随原有room.loadout同步，每名玩家独立选择。大厅、房间与确认本局信息阶段可调整，本局锁定后修改只用于下一局。皮肤不属于管理员测试项目，所有游戏客户端均可使用。

官方皮肤表记录162款命名时装。首次接入119款；2026-10-07对照两个仓库后，补齐38款缺半身像的时装，当前157款、104名干员，共1268个文件、318套解析后的模型（含4套召唤物皮肤）。这38款使用fexli的同款低分辨率完整立绘（charpack/*b.png），在调配、商店及详情按完整图片缩放显示，标记portraitKind=illustration；原119款头像、半身像及战斗模型配置保持。

补充核对来源：[isHarryh/Ark-Models](https://github.com/isHarryh/Ark-Models)，固定提交8a3857c250a5c271429aefa82c660ff35803166e。43款均找到同款基建模型记录，部分有动态立绘；该库不提供干员战斗正背面模型，不能将基建小人直接用于战斗。新增实际素材来自fexli的头像、charpack完整立绘及spine战斗目录，没有把无用途的基建或动态立绘下载进资源包。逐款核对记录见[skins-comparison.json](../tools/assets/skins-comparison.json)。

剩余5款仍缺完整战斗模型，没有开放选择：魔王“追悼”、安洁莉娜“夏卉FA017”／“质素访客”缺背面；浊心斯卡蒂“升华”／“红女爵”缺正背面。详情记录在tools/assets/skins-source.json与data/assets.json的skinSource.unavailable。没有完整时装的干员显示默认外观及素材未完整的说明。此次不包含动态立绘、基建模型、语音包或技能特效皮肤。

默认模型、战斗规则、干员与道具数值没有改动。所选皮肤用于调配预览、头像、商店立绘、准备棋盘、战斗及队友查看；同一共享战场的两个玩家使用相同干员也可使用不同皮肤。资源提供了对应皮肤的召唤物则随主人切换，否则使用原召唤物外观。技能与战斗音效仍沿用原角色。

## 下载与维护

新增素材位于public/assets/skins/，选择目录与Spine元数据并入已有data/assets.json，不增加原生客户端的固定数据类型。皮肤ID由服务器按当前干员和可信清单校验；不能提交文件路径、URL、其他干员的皮肤或隐藏／精锐装配键。

现有v0.2.8资源包客户端无需重装。更新服务器后重启客户端，在局外准备新增内容；内容哈希一致的旧文件继续复用，仅下载缺失或变化文件。后续同版本启动不再下载这些素材；开局仍进行小型版本校验，战斗状态与结果仍须联网。局内缺资源不会回退到HTTP，需回大厅修复。

当前资源包为6816个路径、411.1MiB压缩包；初次无缓存客户端下载完整包，已有资源的客户端下载缺失的独立内容块。从此前119款皮肤版本更新时，原6506路径中6505个内容保持，仅assets.json更新；新增文件中相同内容块还可复用，实际缺少302个独立内容块约111.7MiB。资源包版本：cf56559057057c84eb2d99c11ed900145efc1f456a3ca43a4a65c86d14740416。安装包内嵌相同资源时直接校验并导入本地。

重现固定版本素材：node tools/fetch-skins.mjs。它采用Git稀疏检出，仅读取素材，不执行上游代码；按Git blob SHA-1校验原始字节，再按Spine解析器验证图集、贴图和骨骼。Windows的上游换行设置由原始Git对象读取规避。已下载后可执行node tools/fetch-skins.mjs --offline重新生成清单，然后node tools/build-resource-pack.mjs。

来源索引固定提交，重复执行不会自动切换上游版本。后续补充皮肤时需重新核对上游皮肤表、头像／半身像／完整立绘及战斗模型目录，并更新skins-source.json；只有完整且解析通过的皮肤才可发布。双仓库比较固定到对应提交，不能凭相似文件名将BuildingSkin当作战斗模型。普通fetch-assets重建及--prune保留已发布皮肤，缺少皮肤文件时拒绝写入缩水清单。

## 数据保护与发布

只扩展客户端原有sp.pref.loadout的可选skin字段，格式版本保持1，旧技能／模组继续有效，未设置皮肤时使用默认外观。服务器只在会话和当前对局中持有皮肤选择；不迁移账号或排位数据库，不改密码、账号ID、权限、赛季、成绩、历史、审计或测试开放设置。

更新必须等待对局结束并停服，通过tools/update-project.mjs --stopped先备份并保留config、storage、自定义外部数据及签名；不要直接解压覆盖部署目录。轻量客户端下载保持原版本。包含新皮肤的完整Windows／安卓包保存在mobile/full-dist/，不随服务器源码包上传、不开放服务器完整包下载。

- 原装配、模拟、账号、更新保留、客户端分流及排位测试继续作为回归检查。
