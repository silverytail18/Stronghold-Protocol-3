# 雪境向导冰爆修订 0.3.9

2026-10-10，用户授权按确认方案实施。仅开局启用「岁与企鹅」后载入本局克隆；不新增干员。山路招募与六名雪境向导成员保持，原谢拉格伤害、成长、寒冷叠加冻结、免疫、抵抗与禁用机制继续沿用。此文覆盖0.3.5雪境向导的目标数量、冷却及“无额外伤害”说明。

## 实际规则

| 项目 | 2人档 | 4人档 |
| --- | --- | --- |
| 寒冷目标 | 本人存活已部署成员实时攻击范围并集内所有有效敌人 | 相同 |
| 寒冷持续 | 2秒 | 3秒 |
| 首次等待 | 首个有效敌人出现后2秒 | 相同 |
| 寒冷基础CD | 成功投放后12秒 | 相同，可被冰爆返还至最短10秒 |
| 冰爆 | 未解锁 | 成员攻击冻结敌人、实际扣除生命后触发 |

重叠攻击范围内同一敌人，每名博士每轮寒冷只施加一次。冻结、不可选中、未揭示隐匿、睡眠、无敌与免疫寒冷目标排除，可对空。没有有效目标时等待，不积攒投放次数。阵亡不改变开战人数档位，但阵亡、撤退成员不提供范围；技能改变的攻击范围实时生效。

4人档冰爆基础伤害：

`D = 600 + min(触发成员当前攻击力 × 15%, 180)`

当前攻击力包含装备、技能与盟约带来的攻击属性，不选择全队最高攻击力，不复制本次攻击或技能伤害倍率。攻击力500／1000／1200及以上时，D分别为675／750／780。

主目标另受一次全额D法术伤害，命中位置周围1.2格内其他有效敌人各受0.5D。两类目标分别经过原法抗、穿透、伤害倍率、脆弱、护盾与Boss限伤结算；周围半额指减伤前基础伤害的一半，不是主目标最终扣血的一半。主目标从周围列表排除；范围按原圆形范围伤害的身体中心判定。飞行敌人可受伤，睡眠、不可选中、未揭示隐匿、无敌目标不受冰爆选择。

伤害归属实际触发成员，沿用其原谢拉格对寒冷／冻结的增伤及正常伤害、击杀统计。冰爆不额外施加寒冷或冻结、不直接增加盟约层数。原有击杀、承伤等机制按原伤害流程运行。

普通攻击和技能强化攻击可触发；独立技能、持续伤害、溅射、连锁和冰爆本身不触发。同次攻击最多引爆一次，多名本人成员共享CD。判定目标在本次命中前已经冻结，攻击附带的本次冻结不能追溯触发；取消、闪避、完全被盾吸收、零扣血不消耗触发机会。攻击击杀主目标时仍在捕获的命中位置产生周围伤害，不再扣除死亡主目标生命。

## 两套冷却返还

冰爆基础CD14秒，从实际引爆时开始。冷却期间，本人存活成员实时范围内敌人每次新进入冻结，返还0.5秒；每轮最多返还4秒，下一次冰爆不能早于上次10秒。冻结可以来自任意队友，同一冻结事件对每名满足范围条件的博士各计一次，不随重叠成员范围重复计数。刷新已有冻结不计；解除后重新进入可计。首次冰爆前或CD已就绪时不储存返还，下一次引爆重置本轮预算。范围检查直接使用敌人当时身体位置，避免同帧刚生成／移动的敌人被索敌缓存漏计。

每次冰爆返还本人正在冷却的寒冷1秒，只返还一次，与主目标是否被击杀、周围命中数量无关。寒冷成功投放间隔最短10秒，因此同一12秒周期最多有效返还2秒。首次寒冷的2秒等待、尚未开始或已就绪的寒冷不受返还；不影响其他博士的寒冷CD。
