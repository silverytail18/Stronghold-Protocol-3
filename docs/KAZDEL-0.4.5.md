# 卡兹戴尔5.4完整机制介绍（0.4.5）

本说明对应已经接入项目的kazdel-test-6、客户端能力23。先交付服务器候选包，再验证并交最终包；本地修改不代表云端已更新。本轮保留此前5.3整套方案，新增的血卷、剑气和魂火续航规则按用户最新确认实现。

## 先看实战变化

卡兹戴尔开战就有魂火，辅助和治疗也能参与供火。六人后，地面成员有效普通攻击可以在身前卷出范围伤害；九人后变为快速飞行、穿透、可对空的血色剑气。新范围伤害主要看盟约人数、层数和当前魂火，因此低攻击力成员也能参与输出。

魂火仍会被输出、救命和衰减消耗，但不会因累计生成太多而整场永久停产。魂火为零时，血卷和剑气仍有基础伤害；后续有效攻击、受伤和治疗都能重新供火。界面显示本秒供火额度与当前衰减率，方便区分“资源被花掉”和“本秒额度已用完”。

## 血卷、剑气的触发与范围

角色必须有真实卡兹戴尔身份，具有地面部署资格，并且当前没有起飞、浮空或空中状态。合法转职的地面成员同样有效；仅借其他盟约共享效果、但没有实际身份的角色不能触发。

必须是本体**非技能普通攻击实际命中敌人**。消耗敌人护盾也算命中。无敌、闪避、空挥、召唤物、反伤、装备追加伤害、血咒及盟约附加伤害不触发。原生技能仍可正常增伤、供火与普通附燃，但不能触发血卷或剑气。技能状态下被标记为技能攻击的普攻同样不触发。

方向取角色部署朝向，效果从**前方一格的中心**生成；不自动转向远处目标。

- 六人血卷覆盖前方这一格的方形区域。每个合法敌人承受完整伤害，可对空；每名角色独立冷却2秒。血卷约0.45秒的动画不造成多次伤害。
- 九人剑气替代血卷。宽度一格，在前方一格生成后沿朝向继续飞行五格，用时0.5秒；碰到战场边缘会提前停止。五格从生成位置起算，不从角色身体起算。终点0.06秒视觉淡出不再移动或扩大碰撞。
- 剑气可穿透、可对空，同一波对同一敌人只结算一次；共享Boss血池的多个实体也只结算一份。法术和真实伤害是同一波的两部分，不是重复触发。
- 所有敌人获得完整单目标伤害，不按目标数分摊；魂火成本每波只付一次。

## 血卷、剑气如何计算伤害

用P表示当前可信盟约生效人数、L表示魂契层数、Q表示该次攻击触发时的魂火。当前魂火不是新的独立成长层数。

| 效果 | 全额支付魂火时，每目标的减免前伤害 |
| --- | --- |
| 血卷 | 法术：500＋80×P＋2×L＋0.02×Q |
| 剑气 | 法术：800＋100×P＋3×L＋0.03×Q；真实：上述法术数值的30% |

人数、层数和魂火在触发时锁定；剑气飞行途中新增魂火不改变这一波。公式不再乘干员攻击力，也不重复乘卡兹戴尔原生增伤。原有合法敌人减免、脆弱、护盾和Boss单次限制仍遵循伤害引擎，实际掉血及飘字取实际结果。

300层、20,000魂火的例子：六人血卷每目标1,980法术；九人剑气每目标3,200法术＋960真实。若魂火为0，同条件下分别还有1,580法术，以及2,600法术＋780真实。

支付基准C＝1,000＋25×L。血卷目标花费3%C，剑气4%C。例如300层的C＝8,500，血卷目标支出255魂火，剑气340魂火。

实际支出受触发时可用魂火、当前救命预留和输出额度限制。支付不足时，只按“实际支付／目标花费”的比例降低魂火那一部分；人数和层数的基础伤害保留。普攻刚产生的火不会被同一次零魂火波次立即白白花掉。该波完全没有有效伤害或护盾消耗时退回魂火和输出额度，冷却保持；同一次挥出不再叠加旧普通附燃。

盟约效果中的伤害数字与模拟共用公式。休整显示当前阵容开战预估，战斗显示当前魂火及可支付额度下的参考值；显示的是减免前伤害，实际结果看飘字和掉血。

## 魂火容量、开战数量和持续供火

容量随实际成员数、成员常驻生命上限和魂契层数增加。这里N是实际在场、按同名去重的成员数，H是这些成员的常驻生命上限之和。同名普通／精锐或多个复制体只取常驻生命最高的一份；合法转职计入，虚拟人数和短时技能生命加成不虚增容量。

容量K＝向下取整［(2＋0.2×N)×C＋0.15×H］。成员离场或常驻属性变化时重新计算，当前魂火超过新上限的部分截去。

| 档位 | 开战魂火Q0 |
| --- | --- |
| 3人 | 向下取整min(1.3C，C＋4%H) |
| 6人 | 向下取整min(1.5C，1.1C＋5%H) |
| 9人 | 向下取整min(1.6C，1.2C＋6%H) |

开战魂火最终不超过容量；同轮进入合流等后续阶段会继承当前魂火，不再次领开战赠火。

实际生命流转供火：三／六／九人的基础转化率分别30%／35%／40%，每层魂契再加0.03个百分点，血脉另加转化率，总计最高60%。三人仅成员有效，六人起全队真实干员有效。实际受伤、原生治疗、自疗和再生的生命变化可以供火；溢出治疗、纯还债、初始生命设置和退场清理不凭空供火。

原生伤敌供火：三／六／九人分别按有效生命与护盾损失的10%／12%／15%供火。实际成员有效非技能普攻另有每人每秒一次的保底：容量的0.3%／0.4%／0.5%，与该动作的原生伤敌转化量取较大者。群攻一整个动作只拿一次保底；派生伤害不递归生成魂火。

每秒总生成上限R＝max(400＋5×L，当前档位的12%／15%／18%×K)。原生攻击与技能伤敌共用其中35%的额度；生命流转使用剩余总额度。达到上限需等下一游戏秒；容量满时溢出不占额度。累计生成量仅用于统计，已移除两道整场永久停产限制。

首名敌人真正出现后8秒开始衰减。近5秒有有效原生攻击或真实生命流转时，每秒约减少当前魂火0.5%；闲置时约1.5%。使用连续时间计算，暂停不计时，休整不衰减，阶段继承保留剩余保护期、活动时间及本秒已用额度。

## 开技献血、回技与普通附燃

实际成员成功开启技能时失去当前生命10%，最多扣到1生命；之后一秒恢复实际失血的两倍。失去多少就按多少恢复，例如当前1,000生命时先失去100，再逐渐恢复200，实际回血受生命上限、禁疗等规则限制，不额外乘策略或绷带的恢复倍率。此次失血和恢复能供火、能产生魂契表现成长，但不加速血脉成长；阶段继承技能不会重复扣血。

六人起，成员正常随时间、攻击和受击获取的技力增加20%；初始技力和额外赠送不乘此倍率。

不走血卷／剑气的其他原生攻击或技能，可消耗魂火追加伤害：三／六／九人每花1魂火追加1.2／1.35／1.5法术，九人另有1.25真实。每名角色独立0.5秒冷却；攻击目标支出不超过该动作原生伤害的30%，技能为60%，同时受每动作0.2C／0.4C、当前资源与输出额度限制。群攻普通附燃按目标权重分摊；血卷和剑气使用前述整波独立公式。

输出额度上限C，三／六／九人每秒恢复C的25%／约33.3%／50%，避免高速多段伤害一瞬间烧尽资源。符合血卷／剑气条件的地面普攻走范围波次路线，波次冷却期间仅保留原攻击和供火，不再叠加另一套普通附燃。有效原生治疗给受疗成员四秒标记，下一次普通附燃目标支出提高50%，仍受上限约束；不额外改写血卷／剑气公式。

九人时，成功开技且魂火至少1.1C可进入六秒共鸣，独立共享冷却16秒。共鸣将普通附燃改为每花1魂火追加2.75真实伤害，输出额度恢复加快为每秒C；不改变原技能伤害类型。剑气仍使用自己的法术＋30%真实公式，避免与旧公式重复叠加。

## 全图血咒

只要本方还有存活、已部署的实际成员，血咒就能覆盖全场合法敌人，不再依赖成员自身攻击范围。每个敌人出现一秒后开始受到血咒，以两秒为间隔；地面全额，空中双倍。

每次地面真实伤害＝375＋0.25×L＋Q×三／六／九人档的0.05%／0.075%／0.1%；空中再乘2。零魂火保留基础伤害，不消耗魂火。多人血咒取最强一份，共享Boss血池不因实体多而重复结算。

伤害真正生效时，在对应敌人身旁亮起约0.5秒的小血色符记，跟随移动及空中高度，不挡血条。无敌、完全取消、隐藏或已经离场的目标不错误显示标记。

## 契伤、治疗还债、拒死与低血救援

契伤让成员所受敌人物理／法术伤害的一部分延后六秒支付：比例20%＋每层0.03个百分点，最高45%。每人的契伤容量为C，超过容量的部分立即承受；真实伤害、自身生命消耗等不进入这种延后。延后本身不供火，真正发生生命损失时才按生命流转处理。

治疗盈余先还本人契伤；六人起还可接济两格内符合原有受疗条件的邻近成员，最多一人，九人为两人。纯还债不当作实际回血供火。禁疗与隔离等原规则保持。

共享拒死：魂火至少C、冷却就绪且成员受到可拦截的致死伤害时，消耗0.5C免去这一包致死伤害。冷却按消耗前魂火计算，5—10秒，全队共享。原生保命机制先处理，自身生命消耗和强制退场不会被此效果无限拦截。

拒死就绪时，普通转伤预留三／六／九人档的0.5C／0.75C／1.1C；成员低于等于60%生命或个人契伤至少0.25C时，危急预留1.1C。拒死正在冷却时解除该项预留。预留是输出不能动用的部分，不保证当前魂火已达到这个数。

低血救援：成员生命低于35%时，花魂火尽力恢复到50%，每次预算最多1.25C，剩余预算可还选中成员契伤；三人最多一人，六／九人最多两人；共享冷却分别8／6／4秒。九人实际救援回血后，可向合法近敌追加相当于实际恢复量50%的真实伤害。救援不产生额外成长，受原有受疗限制约束。

## 魂契与血脉成长

三／六／九人休整基础增加6／10／15层；上轮普通战斗表现最多再增加18／30／40层。参与战斗满八秒，或已经有一次有效攻击／治疗，普通／精锐获得1／2表现点；短战斗清场且参与至少一秒也可认定参与。每累计流转相当于开战常驻生命25%的真实生命量，再获得1／2点，同名本场取最高一份，普通最多6、精锐最多10。多复制体不能刷同名贡献。

结算取上一普通战斗档位与当前休整档位允许的较低上限，只结算当前仍符合条件的在场同名成员。Boss、隐藏阶段及同轮重放不重复给成长；护盾、纯还债、救援、复活和生命初始化不刷点。开技献血回血的实际生命流转可以贡献魂契点。

目标仍是正常运营约20回合达到700层左右，不是到第20回合自动送700。回归示例按第三回合激活、八回合六人、十二回合九人并有持续战斗表现，第20回合686层；停摆、阵容人数不足、早退或表现较低会少一些。

血脉为2／4人附加盟约，天然成员芙蓉、炎客、华法琳、赫德雷。额外魂火转化：2人2%＋每层0.02个百分点，4人4%＋每层0.03个百分点；原生受疗随层数分别每层增加0.01%／0.02%。四人血脉且魂契激活时，本方真实干员从半血以下恢复至半血以上，获得200＋4×血脉层数的护盾，持续四秒，同名冷却十秒，每轮最多三次。休整基础2／4层，普通战斗表现额外最多8／16层；血脉生命流转点按50%开战生命阈值及结算折半规则处理，新开技献血回血不刷血脉点。

赫德雷策略：全队真实干员原生受疗、自疗和再生恢复量增加15%，与绷带恢复加算；不改变禁疗，不增幅魂契救援、复活和生命重分配。

自愿献血默认关闭，可在休整选择最多两名不同成员。开战四秒后、安全且附近有合法敌人时，每八秒消耗10%开战生命产生魂火；生命安全线、容量空间和本秒生成额度不足时不扣血。

## 特效与界面

剑气使用用户确认的圆弧前缘：竖直刃面，从红色气流连续渐变至橙金和浅亮刃锋，内部两根金线已移除，不画硬红速度线，接地端沿当前行中心移动，仅少量贴地余光与火星。血卷使用相同红色气流、热亮刃尖风格。光晕与拖尾不扩大碰撞范围；暂停和加速跟随战斗时间。
