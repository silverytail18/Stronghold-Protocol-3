# 莱茵生命／专项研究 0.5.1 强度评估

2026-10-12，ABYSS极限难度，14回合与24回合。结论：旧版科技的单格覆盖、频率和后期底伤不足问题已明显改善。原八部署位在24回合成型后可以支撑此次受控波次和首领测试；14回合仍有预算与首领处理短板，合理研究路线比继续全面抬数值更有效。保留试验包默认私有，进入实际经济游玩测试；暂不据此追加全面强化。

## 方法与边界

使用tools/qa-rhine-balance.mjs，实际Match休整元数据、官方buildNormalWave、BattleSpec与原生Battle，合法机器人布阵和当前部署地图，原始DP／技能／召唤／敌人数据，研究通过正式意图花点，不注入999层或无限点数。四种种子17、73、118、131对应四张ABYSS可用地图；14回合普通R1—13，24回合R1—23，末轮单人／四人最终攻势分别覆盖7名普通首领。

主组696场：288普通、128成对消融、280首领。另专项四人组348场（144／64／140），14回合合法一次重置转扫描组292场（104／48／140）。后两组含复用的前期和对照，不能合称1336场独立真人完整对局。只分析实际已完成数据，warnings为空。

阵容与晋升预设，无完整商店搜索、资金／共享库存、购买概率、合成／装备经济或玩家操作水平模拟。R7指定三名精锐、R12指定成型全精锐属于乐观培养假设；无装备，其他附加盟约效果仍在，但其层数不跨回合完整继承。普通损失每波上限10，起始LP26；不计奖励回复，预设发展在LP≤0后仍继续取样。因此“零漏怪波次”和“首领通过样本数”是战斗指标，不是完整局通关率。

最终攻势独立重建首领地图并重新合法布阵，正确转换本半场区域位置；单人初始首领LP15、四人LP60，使用官方血池与150秒后超时扣血规则。不会把前面普通回合剩余LP继承为实测完整对局。四人组复制同一成型莱茵阵容，非混合盟约队伍，且同名T04减速不重复乘算。

主组原八位：R1—2梅尔＋角峰＋隐现；R3—4加入星源、赫默；R5—6梅尔／星源／赫默／星极／麦哲伦＋隐现；R7—9用白面鸮替换隐现；R10—11形成8名；R12起梅尔／星源／赫默／星极／麦哲伦／伊芙利特／塞雷娅／缪尔赛思，调和提供第9计数。额外位组R12再加溯光星源，达到10计数；额外部署位是投入假设，不保证每局可得。专项四人组在原八位把梅尔换淬羽赫默、麦哲伦换溯光星源，首领全部样本实际专项人数4。

普通研究优先T04→T01→T07→T02→T09→T08→T10→T12→T03，再选恢复／救援／穿透／搜卡／访学。队列保留点数等待目标科技，前置通过正式校验。T01优先输出、T02优先前排、T04选实际路径或阻挡前方；不是每图最优手操布局。14回合9—11总点（含策略等），24回合18—21总点，最高29点科技不可能全买。

24回合原八位R19结算599—636层，平均621.75；额外位627—668层，平均650.5；专项四人598—628，平均617.25。约20回合600层目标在预设正常发展样本中接近，但不是经济真人实测。末轮前14回合335—380层／6—7正常点，24回合754—860层／15—17正常点；总收入含十人／策略，不能把奖励点误称每50层超过19点。999层正常仍19，含十人及克丽斯腾最高23，总科技29。
