# 0.3.5 谢拉格扩展

本轮按项目外《策略与附加盟约设计稿》加入岁与企鹅；只新增山路招募策略和雪境向导附加盟约，不新增干员。正式 data/*.json 不变，原谢拉格人数、风雪、成长、技能、属性与冻结接口保留。新内容仅应用到启用 arknights-expansion-v1 的每局克隆。局外调配与百科可浏览，不会因此开启测试包。

## 山路招募

初始目标生命24，沿用策略单选。调度中心首次达到3/4级，各解锁一次免费招募；两次最高3/4阶，延迟领取不提档。共享库存按副本权重生成最多3名不同天然谢拉格普通干员，选择1名；作战区、手牌、暂存区的普通与精锐按 baseId 去重，转职不纳入候选。

机会记录在本局计数器，跨回合保留。展示候选不占库存；领取重新检查未持有、档位和库存，不合法时重新生成并保留机会。奖励沿用原界面、容量和 onGain 路径，不触发 onBuy；手牌已满时沿原规则拒绝领取。前份选择完成后，才按最新持有生成后份。无候选等待后续休整重试。面板显示已领取次数。

谢拉格被本局禁用，或可入池天然成员不足3名，本策略不会进入玩家候选；服务器选择、焦点、超时与 AI 同步拒绝。其他策略保持原行为。

## 雪境向导

附加盟约，作战区不同姓名计数，2/4人，noStack，正常禁用权重10。角峰、哈洛德、雪猎、耶拉、银灰、凛御银灰普通与精锐追加此归属；隐藏形态不入新名单，原归属、技能、模组、皮肤、特质和属性保持。灵知、初雪、大初雪、锏不追加。

每玩家每战一个调度器，开战人数快照决定档位。首个有效敌人出现2秒后，实时检查存活已部署成员的攻击范围：2人投放1目标寒冷2秒，4人投放2目标寒冷3秒。成功投放后冷却10秒；没目标等待，不储存连发。阵亡不降档，但阵亡成员不提供范围；可对空，范围使用原模拟实时 rangeKeys（包括技能与扩展范围）。

优先级：成员正攻击或阻挡且未寒冷 → 其他未寒冷 → 正攻击或阻挡且寒冷 → 其他寒冷；同档按距终点剩余距离及稳定 ID 排序。排除冻结、未揭示隐匿、不可选中、睡眠、无敌及免疫寒冷。调用原 applyStatus(cold)，抗性及重复寒冷自然冻结照旧，原观察者只对真实新冻结事件增长；多人按各自调度共享敌人。无额外伤害、易伤或层数奖励，层数不改变本盟约效果。

## 兼容与保护

版本0.3.5，岁与企鹅 expansion-test-7、能力11；罗德岛保持 ri-mujica-test-6、能力10。客户端重新打开加载新规则，能力10旧页面不能开新版岁与企鹅。16/18/20/24回合、其他包、后台开放、管理员领取与原皮肤保持。新图标复用谢拉格图标，投放为局部代码冰晶效果，固定资源包版本不变。复用兼容安卓/Windows联机安装包，不重建独立单机APK。

实际源码禁用语义：模式静态禁用不计数、不激活；开局随机禁用仅参与“所有归属都被禁才移出库存”的资格计算，不额外关闭仍由合法成员组成的盟约（原企鹅测试已有此约定）。雪境向导完全沿用，不修改原谢拉格激活逻辑。新增归属会按原规则影响入池资格，必须计入测试包的实际影响。山路招募对谢拉格随机/静态禁用均单独退出候选，这是新策略的明确限制，不推广给原策略。原设计稿中“不能重新激活谢拉格”指新内容不直接设置原盟约的 active 状态，不能解读为新增全局禁用规则。

修改前在项目外 reports/kjerag-0.3.5/source-before 保存源码快照，baseline-hashes.json 保存正式数据、配置、持久数据、签名和离线包哈希。验收记录写在同一外部目录，发布包不包含这些私有数据。无数据库迁移，无自动云端部署。

## 固定交付流程与服务器更新

先交候选包和完整安装流程，再运行验证；修复后打最终包。候选文件 Stronghold-Protocol-3-server-light-v0.3.5-20261010-candidate.tar.gz，最终文件 Stronghold-Protocol-3-server-light-v0.3.5-20261010.tar.gz，各自附 .sha256 与公开文件 manifest。最终包生成前不要把候选包视为已验收。

上传包和校验文件到 /root，校验后暂存解压。等待对局结束并用原服务管理方式停服后，执行新包的 update-project.mjs；工具先备份并保留 storage/、config/、.env、有效外部状态路径及签名，拒绝未知数据覆盖。更新前确保沿用原 SP_STATE_DIR / SP_AUTH_USERS_FILE / SP_RANKED_FILE 配置。

```bash
cd /root
sha256sum -c Stronghold-Protocol-3-server-light-v0.3.5-20261010.tar.gz.sha256
mkdir -p /root/w3-stage-0.3.5
tar -xzf /root/Stronghold-Protocol-3-server-light-v0.3.5-20261010.tar.gz -C /root/w3-stage-0.3.5
# 等待所有对局结束，用原管理方式停服；前台实例在原终端 Ctrl+C。
node --env-file="/root/w3/config/server.env" /root/w3-stage-0.3.5/w3-release/tools/update-project.mjs --source /root/w3-stage-0.3.5/w3-release --target /root/w3 --stopped
cd /root/w3
npm ci
node --env-file="/root/w3/config/server.env" "/root/w3/server/index.js"
```

候选安装将命令中的包名替换为带 -candidate 的文件；暂存目录独立使用 /root/w3-stage-0.3.5-candidate。更新工具会输出实际备份路径，记录后留存。轻量联机客户端无需重装或重新下载固定资源，退出重开加载新代码。上线核对版本、旧账号/权限/赛季/积分/战绩、后台测试开放，未选包的正式局和启用包的新策略/归属，禁用提示及招募跨回合保留。
