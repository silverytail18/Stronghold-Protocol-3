# 安卓独立单机版

单机安装包：`mobile/offline-dist/stronghold-protocol-offline.apk`。
包名：`io.stronghold.protocol.offline`，可与现有联机版同时安装。
当前版本：`0.3.0-offline.2`，Android versionCode 为 `2`，基于 2026-10-08 的当前主项目规则和资源构建。
沿用初始单机版包名和签名，可以覆盖安装 `0.2.8-offline.1`，保留该应用自己的本机调配与设置。旧包备份在项目外 `../reports/Stronghold-Protocol-3-offline-030-20261008/previous-offline-028/`。

## 安装与游玩

1. 将 APK 复制到手机，在文件管理器中点击安装；根据系统提示允许该文件管理器安装应用。
2. Android 8.0 或更高版本，使用较新的 Android System WebView。若提示浏览器版本过旧，更新 WebView 后重启应用。
3. 打开“卫戍协议：盟约 · 单机版”。不需要注册、账号、密码、服务器地址或首次联网下载。
4. 选择标准／险境／绝境／终极难度，点击“进入单人准备”。
5. 在准备界面点击“测试内容”，勾选所需内容，保存后开始模拟。
6. 美术、皮肤、模型、音效、固定数据及真实游戏规则已内置。开启飞行模式也可游玩。

单机版全部开放当前测试权限，不读取服务器的普通用户开放清单。

四种回合扩展互斥；标准模拟禁用全部回合扩展。终局 Boss 与隐藏关沿用当前顺延规则，隐藏关仍需要满足原触发条件。

启用相应内容包后，第一回合休整期的快捷测试领取权限也开放。
“岁与企鹅”可领黍；“罗德岛与乐队”可领予愿安洁莉娜及五名少女乐队干员。
开关默认关闭，开启后逐名选择普通、精锐或不领取，每局只确认一次；空位不足整批拒绝，测试副本不能出售或参与普通合成。
测试内容在点击开始时才应用到本局；下一局可以重新选择。
局外调配显示全部可选新干员，可以提前设置技能、模组及皮肤；只有开局勾选对应内容包，干员与偏好才进入本局。保存调配不能反向启用测试内容。

当前版本同时包含主项目的装备表合并修复与祥子音符外观优化，固定资源、178 款已启用皮肤及其模型均随 APK 内置，不启动服务器资源下载器。

## 本机数据与后台行为

- 干员技能、模组、皮肤选择和游戏设置保存在单机应用自己的 WebView 存储中。
- 单机版不登录云端账号、不读取服务器配置、不参与云端排位或排行榜，不同步账号进度。
- 当前局的状态保存在内存中。切到后台自动暂停正在进行的战斗，返回后可手动继续。
- 强制结束进程、退出应用或重新加载会结束当前局；本版本尚不提供跨进程存档恢复。
- 更新时使用同包名、同签名且递增 versionCode 的 APK 覆盖安装，避免卸载后重装。卸载会清除该单机应用的本机设置。

## 本次服务器更新安装流程

**服务器无需更新。** 本次单机版在手机本地运行，没有新增服务器接口或数据迁移。
继续保留当前 `/root/w3/config/server.env`、持久化目录、账号文件、排位数据库及其 WAL／SHM 文件。
无需停止或重启现有 Node 服务，也无需将这个完整单机 APK 放入服务器的轻量客户端下载目录。

本次只需按上述流程安装安卓单机 APK。现有安卓联机版及 Windows 客户端不需要更新。
源码里的服务器打包和更新工具已排除 `mobile/offline-dist/`，防止后续服务器发布误带完整单机包。

## 后续构建与更新

在开发机准备 Android SDK 35、Build Tools 35.0.0 与可用 JDK，并保留原有
`mobile/android/.signing/` 签名备份。构建不会创建或更换签名密钥；缺失时应恢复已有备份。

```powershell
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21'
npm run mobile:offline
node tools/verify-android-offline.mjs
node --test test/offline-packaging.test.js test/server-release.test.js
```

构建工具只复制固定资源、浏览器模块、战斗模块和列明的游戏 JSON 数据到临时目录。
账号配置、密码、玩家存档、排位数据库和私钥均不进入 APK。
原联机客户端入口、认证代码、资源更新代码和基础游戏规则不会被离线适配覆盖。
适配发生在构建暂存副本中，生成包输出到独立 `mobile/offline-dist/`。

更新固定资源或规则时重新构建单机包，并递增 `tools/build-android-offline.mjs` 中的 versionCode 和离线版本后缀。
目前单机版的更新方式为覆盖安装新版 APK；没有运行时远程更新器。
