# 产品房间版本选择

依据2026-11-03用户追加要求，产品服务器采用以下规则，覆盖固定上游中“大厅选择本机版本、房间发起全员投票”的默认交互。

- 新房间使用管理员设定的默认版本；大厅不提供独立的本机版本选择。
- 房主在房间内、开始游戏前直接选择已开放的原游戏版本，单人同样使用房间内选择入口。
- `room.setVersion {version}`由产品层校验账号、房主身份、模拟方式、后台开放策略及版本数据可用性后生效，不建立投票、不等待队友同意。旧proposeVersion消息在产品入口也按房主直接选择处理；投票与取消投票消息拒绝。
- 非房主和观众只能查看；已开始对局不能改版。
- 切换沿用上游applyVersion的数据与内容校验、难度回退、清除旧调配视图、其他成员取消就绪等规则。所有客户端必须先载入并验证对应版本数据后才能开始。
- 管理员改变开放列表和默认版本，不会强制修改已存在房间的版本或运行中对局。房主的后续选择仍须符合当前开放列表。
- 该“原游戏版本”与0.9.14软件版本、客户端0.9兼容系列及资源epoch分别管理。

保留的上游通用Lobby与历史文档仍含投票实现，供固定底座回归核对；所有部署入口进入产品包装，生产客户端不挂载投票组件。不要据历史说明恢复投票或大厅选择。
