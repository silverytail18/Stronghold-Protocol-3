## 使用与生效时间

1. 使用浏览器登录管理员控制面板 `/admin`。
2. 在“测试内容开放设置”下面的“管理员测试工具”勾选“启用测试领取开关”，保存。默认关闭；不需要把岁与企鹅公开给普通用户。
3. 管理员在客户端创建房间，开局选择“岁与企鹅”或“罗德岛与乐队”。仅岁与企鹅时提供黍、克莱门莎；仅罗德岛与乐队时提供予愿安洁莉娜、凯尔希·思衡托、初华、若麦、睦、海铃、祥子；两包同时开启时共九名。每人均可选择普通／精锐或不领取。
4. 仅第一回合休整期显示本人“快捷领取：关”；开启后在头像表格逐名选择普通／精锐或不领取，点击“确定发放”。可以混合等级或只领一名，每局仅确认一次，整备区空位须不少于所选人数。

后台选项保存后立即重新发送已有对局的本人私有状态：关闭隐藏入口并拒绝请求，重新开启仅能恢复仍在第一回合休整期且未领取的入口。已领取副本不撤销、不移动，后续回合不补领。普通用户没有开关或按钮，客户端隐藏不是权限依据。

本人局内开关默认关闭，仅存在当前玩家的 Match 内存，第一回合休整期间重连保留，新局关闭。休整结束后立即隐藏；公共阶段和服务器私有状态都限制显示窗口。服务器检查后台选项、包、真实管理员身份、第一回合、休整期、存活、未准备、未托管、未领取、所选人数对应空位。

副本不扣共享库存，不触发获取／合成奖励，不修改队友资金、手牌或装配，不能出售、普通合成或突变。可以部署、装备和精锐化，战斗结果及排位仍正常计分。

## 模块边界

| 文件 | 职责 |
|---|---|
| server/admin-test-controls.js | 工具目录、后台描述、设置校验、已注册工具的启用判断 |
| shared/test-operator-catalog.js | 可领取角色、普通／精锐ID及对应测试批次；服务器过滤当前局有效条目 |
| server/match/adminTestOperators.js | 第一回合窗口、私有状态、开关与原子领取；无持久化写入 |
| public/js/adminTestControls.js | 后台按服务器目录渲染、收集选项；不导入游戏模块 |
| public/js/ui/testOperators.js | 本人局内开关和头像表格，收集逐名等级选择 |
| server/test-content-access.js | 复用原私有设置文件、原子写入、并发 revision、管理员权限与来源校验 |

Match 只保留两个消息分发分支和私有视图挂点；Lobby 提供动态授权回调，并在后台保存后刷新已有 Match 的私有消息。公共状态、成绩和账号不增加工具字段。PlayerState 保留通用测试副本的库存／合成／出售保护，不再承担具体发卡逻辑。

## 设置兼容

复用有效私有持久化目录中的 `test-content-access.json`，格式仍为1，新增可选 `adminControls.testOperatorGrant` 布尔值。旧文件缺字段时按关闭加载，不重建配置；旧客户端 PUT 未传 adminControls 时保留已有值。新保存继续保留 publicIds、账号、成绩和旧测试公开范围。

后台设置复用现有 revision 与目录版本校验，过期提交返回409；保存失败不更新内存。未知已保存工具键保留为惰性值，只有当前目录中注册的键能生效；新提交未知键或非布尔值拒绝。这使删除某个工具目录项后无需删除玩家数据或重写设置文件。

## 后续更换或删除

- 临时关闭：后台取消勾选并保存即可，不需要发布代码。
- 替换成其他开关：在工具目录注册新的ID与描述，另写对应逻辑／界面模块，保留已有的设置保存和权限接口。不要复用旧ID表达完全不同的权限。
- 永久删除领取：先后台关闭；等所有对局结束并停服后移除工具目录项、局内逻辑与界面模块，再移除 Match 分发／私有视图、Lobby 回调、HUD／actions／protocol挂点。旧设置键可保留，不会生效。
- 测试副本保护：有未结束的对局或其他工具继续使用副本时保留这些通用守卫。删入口不能顺带允许副本出售、入池或合成。

验收见 [SUI-PENGUIN-VALIDATION.json](SUI-PENGUIN-VALIDATION.json)。上线流程见 [SERVER-UPLOAD.md](SERVER-UPLOAD.md)。本轮未部署云服务器。

## 目录扩展与安全约束

在shared/test-operator-catalog.js添加baseId、normalId、eliteId、batch，确保两档角色已由对应包提供。客户端根据本人私有catalog自动显示头像行，无需新增按钮；服务器拒绝重复角色、未知条目、等级缺失和空选择；库存不足拒绝整批，不消耗每局次数。后台和本人的开关可继续独立删除或替换，副本保护保留。
