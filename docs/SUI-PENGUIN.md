## 1. 范围、开局包与数据隔离

| 内部阶段 | 已实现交付 |
|---|---|
| C1 | 可颂、空、企鹅、两人全技能与模组、个人成长、素材 |
| C2 | 年／令／黍普通与精锐、全部技能、4件模组、个人成长 |
| C3 | 岁的两／四成员战斗效果；夕／余归属；独立伤害与参与窗口 |
| C4 | 予愿安洁莉娜三技能、起飞／吟唱／滑翔／弹药／退场续接、成长 |
| C5 | 年／拜松／梁洵策略、共享池回退、奖励上限及可见进度 |
| 联合验收 | 实际开局选择、多人数据一致、客户端模拟、令高级模型、联防、完整结束流程 |

外部仅一个批次 **`arknights-expansion-v1`**，内部阶段不作为多个可独立开启的包。本体注册为 ready，未选该包时不加角色、盟约、策略或旧角色新归属。本体默认未向普通房主公开；管理员房主开局启用后普通成员共同体验，普通房主即使有管理员成员也不会自动启用。采用本体既有“开局前本机选择、room.start 提交”的流程，不另外实现管理员权限体系。排位沿既有计分；自动验收使用内存排位库。

服务端对本局基础数据深拷贝再叠加 overlay；客户端 briefing 前完成同批次数据与素材清单切换，战斗使用本局冻结数据视图。测试技能装配只在本局生效，不覆盖保存的正式装配；退出后恢复正式清单与偏好。素材骨骼缓存仍可共享，但不会把本局规则带到下一正式局。

两组织均为 **附加盟约，isCore=false，测试开局禁用 weight=0**。正式目标是恢复10；保留既有禁用名额和“全部归属受限才排除角色”的规则。予愿仍受叙拉古／灵巧的原禁用影响；权重0不等于六新角色永远不会受禁用。

独立 runtime 来自2026-10-06快照。本体已由其他开发增加皮肤／测试框架内容，不能用旧实验整目录覆盖。未接触真实 server.env、账号文件、storage、SP_STATE_DIR、外部账号／排位数据库或签名；没有数据迁移、重算积分、创建生产账号和云端部署。
