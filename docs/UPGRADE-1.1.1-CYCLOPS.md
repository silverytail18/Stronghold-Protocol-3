# 1.1.1 舟铲铲服务器更新

服务器包：`Stronghold-Protocol-3-server-light-v1.1.1-cyclops-balance-20261108-fix9.tar.gz`。

本更新针对已运行 1.1.0 的服务器，沿用原工作目录 `/root/w3`、`config/server.env` 和 schema2 数据库。更新不清理账号、排位赛季、对局历史或服务器配置；不包含 Android APK、Windows 客户端或原生资源。客户端版本仍为 build48，已有客户端可连接本服务器，无需重新安装客户端。

将 tar.gz 上传至服务器 `/root/updates`。停止当前服务后，在服务器终端执行：

```sh
tar -xzf /root/updates/Stronghold-Protocol-3-server-light-v1.1.1-cyclops-balance-20261108-fix9.tar.gz --strip-components=1 -C /root/w3
cd /root/w3
npm ci --omit=dev
node --env-file=config/server.env server/product/game-server.js
```

如果使用 systemd、PM2 或其他服务管理器，沿用原服务单元的工作目录、环境变量与启动入口：更新文件并完成 `npm ci --omit=dev` 后，通过原管理器启动服务，不要同时手动启动第二个实例。

仍使用 schema1（1.0.0）的服务器，首次切换到 schema2 须先按 [1.1.0 首次切换说明](UPGRADE-1.1.0-EMI-FRIENDS.md)完成管理员确认与数据库迁移；已运行 1.1.0/schema2 的服务器不重复迁移。舟铲铲房间与普通/排位房间隔离，舟铲铲不写入排位积分。客户端资源差量与完整客户端均不在此服务器包中。

本修订包累计包含舟铲铲经验进度、经验购买资金门控及第 5/10/15 回合海克斯候选私有推送修复；fix4 进一步将馈赠/选秀窗口挂到正式游戏页实际使用的 `public/js/screens/game.js` 入口，并补齐 R10 选秀池建立后的本人私有推送。拆分屏幕与实际入口共用独立模式组件，避免后续更新只改到未使用的界面。馈赠图标和选秀头像使用现有客户端官方素材；Emi 仓库未提交的专用 SVG/TFT 素材不包含在内。

原版 pro、罗德岛与乐队、卡兹戴尔、东国、乌萨斯、伊比利亚六包可合用。舟铲铲变体会传入隔离 Match worker，内容规则快照保留变体标识。莱茵生命、回合扩展及其他未适配测试包仍不可用于舟铲铲。

fix5 累计包含 fix4，并新增「主界面 → 玩法大厅 → 舟铲铲」入口。管理员使用普通浏览器打开 `/account`，在「玩法开放」中修改舟铲铲开关并保存。默认保持开放；关闭后禁止新建、以玩家身份加入等待房间和开始新局，进行中的对局及原成员重连保留。设置独立保存在现有私有持久化目录的 `product-mode-policy.json`，重启后保留。详见 [玩法大厅说明](PRODUCT-GAMEPLAY-HALL.md)。

fix6 累计包含 fix5，并在馈赠、征召窗口内新增固定可见的倒计时，重连与选秀换人均沿用服务器截止时间；滚动内容不会遮住时间。新增 [舟铲铲详细玩法与攻略](CYCLOPS-GUIDE.md)，现已按 fix7 实际规则更新。

fix7 累计包含 fix6。为全部 21 回合生成随机敌人表，修复第 17–20 回合连续使用模板默认敌人；分池按开局座位固定，每组至多四人，普通商店、奖励、征召和返还副本均使用本人组池。金/彩阶赌徒可在商店上方「赌徒行动」中选择并确认；服务器校验轮次、次数、目标和生命。修复利息上限及运营重复收入；升级开启新空槽，保留已展示商品。免费三选一来自干员合成晋升，上一版将商店升级缺少奖励列作缺口的说法已更正。补回共用战斗内容隔离函数，消除舟铲铲馈赠模块安装报错。历史多发金币不追缴。维护边界见 [模块接入与后续更新](CYCLOPS-INTEGRATION.md)。

fix8 累计包含 fix7，修复「盟约徽记／盟约之心／盟约之冕」的选择交互。点击卡片后直接进入盟约按钮列表，选目标后点击固定栏「确认选择」；未选择时按钮置灰。支持返回换卡，列表滚动不遮挡倒计时或确认栏。服务端馈赠数值、候选范围与超时规则保持。

更新后，所有玩家须完全退出并重新打开客户端，再从玩法大厅创建新局，以使用完整的新波次表和固定分池。旧局不会补发历史馈赠或重算历史经济。本包取代同日初版及 fix1、fix2、fix3、fix4、fix5、fix6、fix7；仅本地生成和校验，未上传或部署。build48/schema2/contract2/epoch1 与资源保持，无需重新安装客户端。最终 SHA-256 以配套 `.sha256` 文件与交付报告为准。


fix9 接入舟铲铲第一阶段独立四难度敌人曲线，奖励关、出怪数量、路线、时间和移速保持。高难最终攻势共享血池为原版本难度的130%，标准100%；护卫HP为原版R14的1.35倍、攻击1.10倍，部件HP独立保留原版R14，频次有效命中次数保持旧舟铲铲值。配置按局克隆冻结，以revision/hash写入公开、结算和战斗规格，六包worker沿内容哈希接收。统一首领血池入口：此前方案依据GameData的75%系数，但正式入口旧值实际100%，本次三高难实际增加30%。舟铲铲准备按钮和空格不再弹剩余资金窗口，普通模式保持。

更新后所有客户端完全退出并重开，再新建舟铲铲对局。旧局不追算新曲线。独立配置文件 `data/cyclops-balance.json` 必须随包保留。
