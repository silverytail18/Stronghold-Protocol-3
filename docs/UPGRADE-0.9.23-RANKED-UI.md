# 0.9.23 排位规则、手机榜单、山路招募与聊天界面

保留房主的排位开关。开启后，无论是否启用可用的玩法插件/测试包，都按开局时冻结的赛季规则结算排位积分，不额外减半。单人/多人、难度、胜负、隐秘核心、退出、作废和保底仍遵守该赛季规则；管理员中途调整赛季规则不改变已经开始的对局。普通对局不自动计分。测试模式、AI队友、标准难度等现有排位准入和内容包开放版本/依赖/干员冲突保护保持。卫戍认证等级的非官方半额规则与排位积分分开。

手机“赛季与战绩”榜单新增底部常驻“关闭”按钮；窗口内容独立滚动，关闭按钮不随长名单滚出屏幕。横屏和竖屏均可点按，目标高度至少44px，保留点遮罩和Escape关闭。

山路招募原实现存在但未注册进产品策略事件表，导致升3/4级无触发。现补齐事件注册，实际levelUp路径会分别生成最多3个候选的免费招募，最高3/4阶，不招募已持有同名干员，领取后计数，不能重复领。候选与领取规则保持原实现。

聊天按钮改为左下工具组内正常排布，与表情按钮并列，取消固定190px坐标。聊天面板根据按钮位置及视口夹紧，上方展开，随视口和工具组尺寸更新，手机横屏不越界。新增消息图标、未读数量、频道说明、自身消息样式；字体和点击尺寸独立设下限。原文字发送、冷却、历史与表情功能保持。文字面板和表情面板互斥。

无新素材、资源或客户端包。沿用现有Windows build45和安卓横屏版build46（兼容45），资源41ebe63b…、签名和最低构建要求保持。0.9.21账号/皮肤同步及0.9.22等级和文字聊天功能保留。
