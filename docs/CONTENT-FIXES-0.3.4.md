# 0.3.4：助力归属与克莱门莎修订

日期：2026-10-09。范围为两个已启用测试包的本局数据、局外只读目录与克莱门莎二技能渲染。

## 凯尔希·思衡托

普通档已使用正确的`deputShip`，精锐档误写为不存在的`assistShip`，导致英文标识回退显示，且无法计入现有助力规则。精锐档现统一为`deputShip`；两档保持罗德岛／助力。源配置tools/content/rhodes-band.json原本正确，不新增虚构盟约或重复助力实现。

启用罗德岛与乐队后，两档在调配、百科和本局使用同一真实助力记录。搭配另一名助力可启动2人档，休整结束已激活盟约+2层；3人档仍按现有不同姓名或精锐状态计数、+4层。现有全员防御提升与再部署时间×0.7生效，所有其他助力规则保持。

## 克莱门莎

普通与精锐的归属都改为阿戈尔／迅捷，调配、百科、盟约人数、开局禁用及入池资格通过现有成员重建与过滤规则自然跟随。未启用岁与企鹅仍不进入本局。

侵蚀破阵只增长已激活的所属盟约：普通每次阿戈尔2层、迅捷1层，精锐每次阿戈尔4层、迅捷2层；同名每玩家每战共享3次上限。旧精准归属与增长全部移除，对应文本、黑板参数同步。其他干员的精准规则保持。数据生成工具同步阿戈尔／迅捷归属和成长，避免以后重新生成时恢复旧归属。原技能数值、模组目录、头像、模型及管理员领取保留。

## 罗德岛成员调整

用户要求移除魔王与华法琳的罗德岛归属。两名原版角色的普通／精锐及原家族隐藏形态均保留原有盟约、属性、技能、模组与特质，不计入罗德岛天然人数。调配、百科、开局成员过滤和定向罗德岛获取都使用更新后的14名目录：八名新／移入干员，加波登可、休谟斯、寒芒克洛丝、泥岩、百炼嘉维尔、妮芙六名旧干员。

同步删除华法琳额外的罗德岛医疗协同积累特质与生成分支。她原版授予身前干员的成长特质保留：若队友本身属于罗德岛，仍可按原特质增长队友的盟约，这不代表华法琳恢复罗德岛归属。魔王原有追加特质机制也保持。两槽作战终端转职仍沿用既有规则，非天然成员可通过合法装备获得罗德岛。

## 二技能水漩涡

参考用户提供的水环图片，将移动源石荚和停止后的漩涡都映射为持续水环。蓝色深浅水纹、细流、透明中心与独立旋转泡沫，不使用加法混色、白色填充中心、爆炸粒子或屏幕闪光。半径和位置仍读取模拟事件。

public/js/render/waterVortex.js隔离渲染实现，fx.js仅接入事件和生命周期。连续模拟步刷新同一施放者视图，所有副本共用两张按需生成的Canvas纹理，每帧只投影和旋转；最多16个活跃视图，无后续事件时0.24游戏秒内消失，切换／清理战斗时释放显示对象并保留共用纹理。游戏暂停、倍速使用原渲染时钟。

这部分只改外观，不改二技能伤害、固定侵蚀、移动、敌人拉拽、减速、范围或技能持续时间；三技能爆破保持原外观。
