## 一、从本体研究得到的结论

### 敌人怎样变强

以下是多人模式普通敌人相对于其基础属性的倍率。它不是整波难度评分，未包含数量、出场时间、路线、特殊机制和控制免疫。

| 模式 | R3生命／攻击 | R7生命／攻击 | R13生命／攻击 |
|---|---:|---:|---:|
| 险境 | 0.960／0.880 | 1.152／0.968 | 2.867／1.559 |
| 绝境 | 1.440／1.210 | 1.728／1.331 | 3.583／1.949 |
| 终极 | 1.440／1.210 | 3.583／1.611 | 6.687／1.949 |

终极多人在中段存在较大生命阶跃，不能只按每轮小幅增长估计。单人使用自己的曲线：例如R13险境、绝境、终极生命倍率分别为1.866、1.659、2.986，攻击倍率为1.127、1.171、1.772；不能拿多人数据替代单人数据。六种模式逐轮原始值都保存在校准报告中。

20／24回合扩展使用本模式原R13作为基准，新增普通关的倍率不逐轮复利：

| 回合 | 生命／原R13 | 攻击／原R13 |
|---|---:|---:|
| R14 | 1.10 | 1.05 |
| R19 | 1.60 | 1.28 |
| R20，仅24回合扩展中为普通关 | 1.68 | 1.31 |
| R23 | 1.92 | 1.40 |

20回合扩展的最终攻势在R20，24回合扩展的最终攻势在R24；领袖共享血池分别为原来的1.30／1.50倍，不能套普通关生命倍率。普通敌人到R23的成长仍为长期阵容留出了反超空间。

所有本文的冷却和每秒伤害都使用**模拟秒**。本体战斗为2倍速，后期普通关115真实秒对应230模拟秒；必须在同一单位下比较。

### 原版盟约怎样成长

本体各盟约上限都是999。下面把成长条件和收益放在一起比较，避免把“层数相同”误认为“投入相同”。

| 原版核心 | 主要成长来源 | 层数提高什么 | 本次设计参考 |
|---|---|---|---|
| 炎 | 购买干员；小满、夕按本轮获得数量成长；获得特质 | 攻击每层+0.9个百分点；6／9人有炎佑 | 经济投入可以积累高层，不能把100层当终点 |
| 萨尔贡 | 菲莱、百炼嘉维尔开技能；莎草首开；缇缇控制 | 技能触发的攻速／攻击增益持续时间每层+0.22秒 | 战斗行为赚永久层数，同时要看技能实际频率 |
| 维多利亚 | 薄绿、维娜、号角按不同阶构成成长 | 持装备者伤害倍率每层+0.008；6人有每件装备攻击加成 | 构筑与装备投资决定成长和输出，不能只看伤害系数 |
| 谢拉格 | 敌人有效进入冻结；特质授予与购买 | 对寒冷／冻结目标伤害倍率每层+0.01；寒风更久 | 成长与控制覆盖相关，不能假设对所有敌人全程生效 |
| 拉特兰 | 消耗弹药；空弦站位成长 | 弹药倍率每层+0.015；6人消耗弹药提升攻击 | 快速行动可以一场赚几十层，但有消耗与上限 |
| 阿戈尔 | 吞噬、击倒、自身被击倒等 | 生命每层+1个百分点；吞噬与前三次免费再部署 | 卡兹戴尔叠层生命应保留，但其系数应低于生命专精核心 |
| 叙拉古 | 刷新、击杀、精锐特质授予 | 攻速每层+0.8；隐匿持续每层+0.4秒；附带真伤成长 | 成型后可以高速滚雪球，长局允许很强 |
| 卡西米尔 | 部署与重新部署特质 | 部署叠攻击的上限每层+1个百分点；6人附加真伤 | 上限提高不等于开局自动获得，要保留兑现条件 |

用原版普通形态特质作几个有明确动作条件的算例：薄绿＋维娜＋号角，在六个不同阶且维多利亚为最高层激活盟约时，一次休整共42层；圣约送葬人实际消耗49发子弹拿满49层，再加空弦自身和身前各3层，共55层；菲莱开2次、百炼嘉维尔开3次、莎草首次开、缇缇12次有效控制进入，共56层萨尔贡。

这些是**指定条件下的收益，不是实测平均每轮收益**。精锐、购买、投资人、特质授予与通用道具还能改变进度。原版特质的部分“每场上限”按特质实例计算，例如精锐荒芜拉普兰德授予多位成员的击杀特质，不能误认为全队合计只允许100层。

据此，卡兹戴尔保留较快的血量贡献成长是合理的；需要控制的是其兑现方式，以及容量、生成额度、增伤被连续相乘后的输出。

## 二、最终保留与调整

整体仍为**卡兹戴尔3／6／9、血脉2／4、11名天然核心、7名新增干员、两条策略、两件装备，没有路线选择**。魂契与血脉均支持0—999层。

| 项目 | 本次最终设计 |
|---|---|
| 基础生命 | 保留3／6／9人+10%／15%／20%，每层另+0.5个百分点，一直成长至999 |
| 干员增伤 | 保留每层+0.2%／0.35%／0.5%，限定核心受益者自身物理、法术、真实伤害 |
| 魂火伤害 | 不再叠乘上述干员增伤；以容量和实际支出成长 |
| 产火额度 | 全程使用3／6人10000＋80×层数，9人14000＋180×层数；取消100层后的额外加速 |
| 每秒产火上限 | 全程400＋5×层数；取消100层后的额外加速 |
| 血咒基础 | 3／6／9人25／35／45，每层+0.1／0.15／0.2，只计算前100层；后段不继续增长 |
| 血咒魂火加伤与范围 | 当前魂火×0.01%／0.015%／0.02%；限真实卡兹戴尔成员敌方攻击范围的并集，地面半额、空中双倍 |
| 九人高层质变 | **650层解锁魂契鼎盛：干员伤害再加100个百分点，魂火释放伤害翻倍** |
| 成长节点 | 保留开局储备、500层第三邻敌、750层开战半池；取消250层额外拆真伤段数 |
| 拒死 | 保留10秒基础、触发前魂火最多减CD50%、全队共享；实际5—7.5秒 |

此前把魂火释放也乘每层增伤，会让“更多魂火×更多伤害倍率”持续放大。本稿把这部分改成**明确的高层质变**：650层前正常发展，650层以后强阵容获得双倍魂火伤害。高层奖励仍然很强，但来源和触发条件更容易理解、测试和调整。

## 三、完整核心规则

设L为魂契层数，范围0—999；**C＝1000＋25×L**，全队魂火上限2C。C同时是每名核心受益者的基础契伤容量，各人的契伤分开记，不共用一份生命池。

| 效果 | 3人 | 6人 | 9人 |
|---|---|---|---|
| 最大生命 | +10%＋0.5%×L | +15%＋0.5%×L | +20%＋0.5%×L |
| 自身伤害加成 | +0.2%×L | +0.35%×L | +0.5%×L；鼎盛时另+100% |
| 谁能供火 | 核心受益者 | 全队真实干员 | 全队真实干员 |
| 休整基础成长 | 3层 | 6层 | 9层 |
| 上一普通战斗贡献上限 | 12层 | 24层 | 45层 |
| 自动释放间隔 | 8秒 | 6秒 | 4秒 |
| 一次最多救援人数 | 1人 | 2人 | 2人 |
| 治疗盈余可帮助邻近契伤成员 | 不扩散 | 最多1人 | 最多2人 |
| 单正式轮生成额度 | 10000＋80L | 10000＋80L | 14000＋180L |

生命百分比沿本体属性规则加算；“伤害加100%”也是与本盟约每层伤害加成相加。650层九人自身伤害加成为325%＋100%=425%，即原受益伤害的5.25倍，**不是把4.25倍再乘2**。

自身增伤覆盖实际享受核心效果的干员原生普攻、技能、反击及自身持续伤害中的物理／法术／真实生命伤害。它不提高治疗、元素积累、元素爆发、召唤物，亦不再提高本盟约的血咒、伤敌释放、溅射或救援余焰。原生伤害按本体防御、法抗和伤害管线处理；高增伤不能替代高防敌人所需的合适伤害类型。

### 血量变化与成长

实际受伤、真实治疗、自疗、再生、主动卖血、合法献血和原生血量重分配，都按实际生命上升／下降分别供火。受伤后回血可以赚两次魂火。转化率为20%＋0.1%×L，再加血脉加成，最终最多40%。护盾吸收、无效治疗、纯偿债、初始化和清理不供火。盟约自身救援的实际回血照常供火，仍受储存、每秒和单轮额度约束。

所有真实核心受益者还可为长期成长贡献：每累计变化达到自身**开战最大生命的50%**，普通形态贡献1层，精锐贡献2层；个人每轮分别最多4／8层。同名只计最高的一份，最后再受全队12／24／45层上限约束。外援六人后可以供火，不会仅凭供火资格获得核心成长资格。

供火与成长记录分开：**魂火救援的回血供火，但不赚永久成长层数**。原生血量变化与契伤到期真实扣血可赚成长，魂火额度用尽后的合法实际血量变化仍可记录有限成长。纯偿债、护盾吸收、场景加载和重复副本不赚成长。

贡献按上一普通战斗的形态、开战生命与核心档位记录；下一休整贡献者仍须部署并合法受益。精锐升级不追溯翻倍，临时卖出不领取；全队贡献上限取**上一战斗档位与当前休整档位中较低的那档**。首次休整没有上一轮贡献，联防、Boss与隐藏关不额外刷这笔贡献。同一轮只结算一次。

因此，正常休整单次最多15／30／54层；升到6人或9人的第一轮，不能凭新档位提前领取上一战斗没有赚到的贡献。原版特质与道具的合法叠层仍可存在，但这份休整账本不是战斗特质事件，不额外触发魔王身前特质加层。

### 契伤、治疗和拒死

敌方物理／法术伤害在原生减伤与护盾处理后，可将一部分生命损失延后：前100层为20%＋每层0.1个百分点；100层后每层另+0.01个百分点，999层为38.99%。每人最多积累C契伤，超出容量部分即时承受；未偿还的债6秒后结算。它是延后，不是永久减伤。真实伤害与主动卖血不享受这条延后。

原生治疗先恢复真实生命，再用合法盈余偿债；6／9人可按既有邻近规则帮助最多1／2人偿债。纯偿债不产生魂火、不记成长，也不能再次乘血脉治疗倍率。

核心受益者遭遇仍会致命的合格伤害时，如果魂火至少C且共享CD就绪，消费0.5C，免疫这次剩余致命伤害，并取消本包新增契伤。**冷却＝10×[1－50%×触发前Q/(2C)]秒**，半池7.5秒、满池5秒，触发时锁定；全队只用一个CD。

它不回血、不清空旧债、不持续无敌。同帧连续三包伤害只保护第一包满足条件的致命伤害。原生锁血优先；可以保护合法到期契伤包，但不免除主动卖血、献血或史尔特尔强制退场。

### 自动救援与伤敌

魂火至少100且释放冷却就绪时，系统按8／6／4秒间隔自动处理。先救生命低于35%的核心受益者，最多恢复到50%，一次总支出不超过1.25C；先恢复实际生命，再合法偿债，每魂火换1点实际恢复／偿债。九人救援额外造成实际回血量50%的真伤；鼎盛时这段真伤翻倍，**回血和偿债不翻倍**。

无危急受益者才伤敌：最多消费C，3／6人造成支出等额法伤；九人造成等额法伤＋125%真伤，另最多2名邻敌各受半额法伤，500层后邻敌最多3名。650层且九人时，这些伤害全部翻倍；支出和冷却不变。

若拒死就绪且存在核心受益者，伤敌保留C；救援可使用这笔预留。全部资源使用同一魂火池与生成额度，溢出也占额度，支出不会返还额度。不能把伤敌、救援、拒死和满池血咒都算成同时持续满额。

伤敌仍要求原生合法攻击范围和对空资格。原生领袖单次大伤害取消、屏障、无敌、频次目标与共享血池规则照常；不根据限伤值临时拆段绕过。原有九人法术＋真伤结构保留，取消此前250层新增的真伤二次拆段。

## 四、血咒：前期范围内对空补伤

血咒的用途是帮助缺少远程输出的早期阵容磨掉空中敌人的一部分生命。**只有敌人处于至少一名本玩家卡兹戴尔成员的当前敌方攻击范围内，才受到血咒。** 它仍能作用于地面敌人，但地面伤害仅为参考伤害的一半。

先算参考伤害D，H＝min(L,100)：

| 档位 | 每模拟秒参考真伤D | 空中目标 | 非空中目标 |
|---|---|---|---|
| 3人 | 25＋0.1H＋当前魂火×0.01% | 2D | 0.5D |
| 6人 | 35＋0.15H＋当前魂火×0.015% | 2D | 0.5D |
| 9人 | 45＋0.2H＋当前魂火×0.02% | 2D | 0.5D |

魂火加伤是实际当前魂火数量的百分比，例如九人10000魂火只增加2点参考伤害。三档比例均为此前0.5%／0.75%／1%的1/50。初始基础伤害略高，补偿前期没有层数与魂火时的空窗；成长显著降低，100层后基础不再增加。**魂契总层数仍上限999，生命、成员增伤、容量、产火额度与血脉继续长期成长；只有血咒基础单独限制到前100层。** 高层魂火池扩大仍能稍微提高魂火加伤。

空中保留原有双倍，非空中再减半，因此同条件空中伤害是地面的四倍。鼎盛和成员增伤均不放大血咒。九人999层满池时，地面仅37.695、空中150.78真伤／模拟秒，比5.0的1343.75／2687.5分别减少约97.2%／94.4%，同时失去全场覆盖。

### 范围怎样计算

- 提供范围的必须是存活、已部署、未退场的真实卡兹戴尔身份干员，包括天然成员和旧旗＋变形同构体合法转职成员。普通外援、仅通过调和继承效果而没有该身份的干员、召唤物、虚拟人数和其他玩家不提供覆盖。
- 取干员当前敌方攻击范围，随朝向、位置和实际攻击范围变化更新。华法琳等医疗的治疗范围、魔王的恢复范围不变成敌方攻击范围。陨星强化普攻的爆炸半径、W地雷的爆炸区域也不额外扩大血咒范围。
- 范围判定**不要求提供者本来能对空**。空中敌人在近战卡兹戴尔成员的攻击格内也可受血咒，才能实现缺乏原生对空时的补伤；这不改变该成员普攻或技能的对空资格。
- 不要求干员正攻击这个目标。已有敌方攻击范围的成员即使晕眩、缴械或暂停普攻，仍提供几何覆盖；死亡、撤退、未部署立即失去覆盖。
- 多个成员范围重叠时，同一敌人仍只有一份血咒。敌人离开所有覆盖区域立即停止，不保留离圈持续流血，也不补发之前没受的伤害。
- 敌人出生满1模拟秒后，每模拟秒按当前位置与当前魂火判定。联防同源取最强一份，共享领袖血池去重；原生无敌、护盾和特殊伤害规则照常。血咒不消耗魂火、不当作普攻，不供攻击技力或吸血。

早期依靠站位让飞行路线经过近战前方和远程覆盖区，中期由陨星／W补足真正的远程清敌能力。后期血咒维持少量补伤，把主要输出空间交给成员技能和魂火释放。

**为什么质变最终选650层？** 按“R3达到三人、R7六人、R11九人”的条件进度，上一轮贡献持续拿满时，R19是621层、R20是675层。750层在这种条件下要到R22，奖励略晚。650层能使发育很好的阵容在20回合前后进入强势期。它按实际发育触发，不在R20无条件送给所有阵容；极优秀的更早成型阵容可以更早兑现。

此前“R1三人、R4六人、R9九人且每轮拿满”的极乐观算例，修正升档轮结算后为R13 **420**、R19 **744**、R23 **960**，不是453／777／993。本稿不再承诺普通流程必达250—450层；999是长局充分发育或搭配原版额外叠层的追求。
