# 企鹅物流重做与百科大全（0.3.1）

修订日期：2026-10-09。适用于联机项目。企鹅物流仍仅在开局选择“岁与企鹅”后进入本局；不改变当前权重10与开局禁用算法。罗德岛与乐队、既有皮肤与回合扩展保留。

## 企鹅物流

2—3名不同成员：休整结束基础增加3层，本队携带持续战斗装备的干员固定攻击+40、防御+60，攻击与防御各+5%。4名以上：基础成长改为5层，固定攻击+80、防御+100，攻击与防御各+10%。四人替换两人；每名干员一次，不随层数增长，不作用于队友、召唤物或装置。使用现有固定值及同类百分比相加渠道，固定值先计算。移除旧企鹅穿透、攻速、减速。可颂3/6、空2/4及灵巧成长条件、其他层数来源保持。

12／30／50层里程各补给一件装备，层数不消耗，每人每局最多三件，每次休整开始最多一件。完成既有入休整效果并重算盟约后，在玩家操作前读取当前层数与成员人数，立即发放；2—3人普通、4人进阶。不在休整中额外触发，不提前锁定品质，跨多个里程后逐次休整领取。重连与重复入口不能重发。候选是本局商店合法、1—4阶、不高于当时商店等级的持续战斗装备，排除消费型道具；奖励走正常合成、出售和临时库存流程。提供本人补给进度效果。

数值集中于server/sim/content/expansion/penguin-balance.js；补给结算独立于战斗模块，Match.enterPrep只在正常入口调用。批次expansion-test-4，客户端能力8；旧客户端必须刷新代码才能启用此包，防止新旧模拟规则混用。

## 百科大全

标题页左上与模拟协议选择页左侧，“百科大全”在“玩法说明”左边；房间页也提供入口。两个页签为盟约大全与装备大全。当前包含27个盟约、60组普通道具／装备及对应进阶形态。支持按名称、效果、测试包搜索；盟约显示核心／附加类型、人数、计数范围、不同层数的实际数值、成员普通／精锐成长特质；装备显示等阶、来源、消耗性、合成、两种品质效果、追加盟约与使用条件。

目录来自正式数据与已实现内容模块的独立克隆，绝不写入运行数据缓存或Match。测试条目标记包名，所有账号可浏览，只有开局启包才可在本局获取。复用现有本地资源，无新增图包。桌面、窄屏滚动、搜索、关闭交互需真实客户端验证。
