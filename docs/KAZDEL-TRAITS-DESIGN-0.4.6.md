# 卡兹戴尔专属特质：怪潮守线方案

2026-10-11设计稿。用户在0.4.6中期数值验证后追加要求：针对挡数不足，为每名卡兹戴尔成员设计专属特质。本文件是完整设计，尚未写入战斗规则；0.4.6服务器包实际包含的内容以KAZDEL-0.4.6.md为准。不能把本文件当作已经可玩的机制。

## 要解决什么

当前红豆、炎客、史尔特尔基础挡数都是1，赫德雷2，泥岩3。常见的泥岩、炎客、红豆前排总共只有5点挡数；有人倒下或暂时停止阻挡时，会迅速漏怪。部分大体型敌人还会一次占用多点挡数，5点不一定能挡5个敌人。辅助、高台角色不应靠增加面板挡数直接接敌。

中期需要三件事一起发生：前排接得住更多敌人；多挡时不会立刻被围攻打倒；被挡住的敌人更快被后排清掉。专属特质保留原技能、天赋、模组的身份，增加一条符合定位的卡兹戴尔能力。

## 全体规则

- 仅本局启用卡兹戴尔内容、盟约激活、角色具有实际卡兹戴尔身份时有效。3人开启专属特质；6、9人强化数值及各档明确列出的机制。魂契层数只影响伤害、护盾、回复等数值，不解锁机制、不增加挡数、不缩短控制冷却。
- 6人时，正常具备阻挡能力的地面成员挡数+1；9人提升到+2。是替代档位，不把+1与+2再次叠加。地面成员正在阻挡时额外承受的敌人物法伤害降低10%／15%；与已有不同来源减伤相乘，避免加到100%。
- 保留技能、天赋和控制导致的零挡或无法阻挡状态：泥岩S3前段、起飞、浮空等期间，额外挡数不让其重新接敌。原本不具备地面阻挡资格的角色不能用这条规则变成前排。
- 普通、精锐都有同一专属机制，数值跟随正常属性和盟约档位，不为精锐额外解锁机制。同名特质对同一目标只取最强一份，不靠复制体叠满减伤、挡数或控制。
- 专属护盾、增挡、减速、减防要有清晰短提示。角色详情显示原始挡数、盟约补挡、特质临时补挡、技能补挡以及实际当前总数；零挡原因优先显示。
- 既有血卷仍是地面成员有效非技能普攻触发、每人2秒；剑气仍是每人1秒、一格宽、0.5秒飞5格。专属特质不会把技能、召唤物或高台攻击变成血卷／剑气触发器。

## 转职成员

合法转职成员继续完整获得共同补挡、承伤保护、魂火、血卷／剑气等盟约效果。按原定位获得一条通用卡兹戴尔特质，避免必须凑齐天然名单才能守线，但不复制某名天然干员的专属招牌。

| 转职定位 | 通用特质建议 |
| --- | --- |
| 地面重装 | 正在阻挡时，每4秒获得常驻最大生命3%／4%／5%护盾，持续3秒；同名不叠。 |
| 地面先锋／近战输出 | 对自己阻挡目标的原生伤害+10%／15%／20%，按原生增伤同一管线相加；不把血卷或剑气再乘一次。 |
| 治疗／辅助 | 有效原生治疗后，为受疗地面成员减伤4%／6%／8%，持续2秒；同名取最强，遵循原受疗限制。没有原生治疗的辅助可改为保护自己范围内受压最高的一名成员，冷却4秒。 |
| 远程伤害角色 | 原生伤害命中被实际成员阻挡的目标后附加20%／25%／30%减速，持续1秒；同一敌人冷却4秒、同名共享、遵循免疫。 |

依据实际部署资格、原生攻击方式和职业选择一条，双职业／重复转职不叠多条；天然成员转职后继续使用自己的专属特质。召唤物、借盟约共享但没有实际身份者不获得这些特质。

## 中期阵容会有什么变化

泥岩＋炎客＋红豆的永久挡数，从当前3＋1＋1＝5，变为六人档5＋2＋2＝9；华法琳临时接防可再补1。泥岩开S3前段等零挡期间仍会失去它的接敌份额，需要安排站位和开技时机。多挡重量敌人仍可能占用多个位置，不能把9点等同为9个精英。

炎客负责同时清理自己挡住的敌人；红豆帮助第二路；芙蓉、华法琳、魔王维持前排；W延缓后续怪潮，陨星处理重甲，后期史尔特尔和逻各斯解决高法抗与精英。新特质加上已实现的中期数值加强，目标是守线和清线同时改善。
